Welcome to Ocean Morph

Ocean Morph에 오신 것을 환영합니다. 깊은 바다처럼 유연하고 가벼운 개발 환경을 제공하기 위해 설계되었습니다.

핵심 특징

Deep Blue 컴파일

로컬 리소스 부담 없이 빠른 응답 속도를 보여주는 최신 엔진을 탑재했습니다.

Aqua 신택스

코드를 작성하는 즉시 아쿠아 시안 컬러 하라이팅으로 가독성을 극대화합니다.

환경 설정 (Setup)

초기 설치 및 프로젝트 세팅 방법입니다. 아래 명령어들을 실행하세요.

1. CLI 도구 설치

$ npm install -g ocean-cli
$ ocean --version

2. 새 프로젝트 생성

원하는 디렉토리로 이동한 후, 초기화 명령어를 실행합니다.

$ ocean init my-ocean-project
> Success! Project created in /my-ocean-project

주요 기능 (Features)

바다 테마 디버그 도구 및 내장 터미널 기능입니다.

딥 오션 디버거

디버깅 모드에 진입하면 조용하고 차분한 딥 블루 와이어프레임 뷰로 전환됩니다.

시 폼(Sea Foam) 터미널

터미널 출력 시 시인성이 뛰어난 아쿠아/시안 폰트를 적용해 눈의 피로를 최소화합니다.
